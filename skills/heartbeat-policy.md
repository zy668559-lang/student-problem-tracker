# Heartbeat Policy

- Heartbeat is a lightweight weekly rhythm layer, not a new infrastructure system.
- It should answer only a few recurring questions:
  - 这周主盯什么
  - 哪一步还没稳
  - 下周先做什么
  - 现在该不该继续追
- Heartbeat must stay scoped by `student_id`.
- Heartbeat should consume existing evidence, recheck, weekly report, and membership state instead of inventing a parallel truth source.
- Heartbeat Lite must not require payment, worker, or cron to exist first.
