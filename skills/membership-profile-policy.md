# Membership Profile Policy

- Membership is per `student_id`, never per parent account summary only.
- Three tiers only at current stage:
  - `trial`
  - `self_service`
  - `coaching`
- Membership copy, CTA, and backend capability checks must stay aligned.
- Trial should not silently receive self-service or coaching rights.
- Admin manual operations must leave logs with actor, time, before/after, and note.
- Do not introduce payment semantics until billing is explicitly in scope.
