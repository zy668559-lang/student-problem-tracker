# M1_INTERACTIVE_MATH_DEMOS

## 目标与边界
- 目标：做 4 个直播可展示的数学交互理解卡样板，证明“陈老师能看见孩子的卡点，并能演示为什么会卡”。
- 边界：只新增 `/showcase` 或 `/demo` 层，不进入主产品主链。
- 技术取向：稳定第一，不追求花哨动效。
- 端侧取向：桌面端优先，移动端可打开不崩。

## 页面 1：函数样板1（顶点 / 开口 / 平移）

演示内容
函数图像里最容易卡的三个点：顶点位置、开口方向、平移方向。通过拖动顶点与开口，让家长直观看到“为什么一换条件就乱”。

页面结构
1. 顶部：标题 + 一句结论（先说孩子卡哪）。
2. 左侧主区：抛物线坐标系与可拖拽顶点，开口方向切换。
3. 右侧说明区：卡点说明、错误原因、本周要盯。
4. 底部操作条：重置与演示按钮。

按钮位置
- 右侧说明区底部：主按钮“演示为什么会卡”。
- 底部操作条右侧：次按钮“重置”。

家长文案（大白话）
- 现在不是不会画，是“顶点往哪挪”一变就乱。
- 这周先盯：顶点坐标看符号，开口只看 a 的正负。
- 别急着刷题，先把“向左是减、向上是加”记稳。

直播 30 秒讲法
- “这孩子卡的不是公式，是顶点和开口一变就乱。”
- “我拖一下顶点，你看他就会把左右上下的符号弄反。”
- “本周就盯两个动作：看清顶点符号，看清开口正负。”

## 页面 2：函数样板2（图像和条件连线）

演示内容
把条件和图像一一连线：给出对称轴、与坐标轴交点、单调区间等条件，点击条件高亮图像对应部分，展示“条件一换，图像哪里会变”。

页面结构
1. 顶部：标题 + 一句结论（先说孩子卡哪）。
2. 左侧主区：函数图像与高亮区。
3. 右侧条件区：条件列表 + 对应连线提示。
4. 底部操作条：重置与演示按钮。

按钮位置
- 右侧条件区顶部：主按钮“点条件看图像”。
- 底部操作条右侧：次按钮“重置”。

家长文案（大白话）
- 现在不是不会算，是“条件和图像对不上”。
- 条件一换，他不知道图像哪一块该跟着变。
- 这周先盯：条件 -> 图像，一条一条对上。

直播 30 秒讲法
- “看这里，条件一动，图像这块就跟着变。”
- “孩子卡在‘条件不落地’，所以题一换就乱。”
- “本周只做一件事：条件和图像一一对上。”

## 页面 3：几何样板1（辅助线什么时候该出）

演示内容
给出一个基础图形与题干，提供三条候选辅助线，点击后展示是否能把已知连到要证，解释“为什么这条线能通，其他线只是在凑”。

页面结构
1. 顶部：标题 + 一句结论（先说孩子卡哪）。
2. 左侧主区：几何图形 + 可选辅助线。
3. 右侧说明区：卡点说明、出线逻辑、本周要盯。
4. 底部操作条：重置与演示按钮。

按钮位置
- 右侧说明区底部：主按钮“演示正确出线”。
- 底部操作条右侧：次按钮“重置”。

家长文案（大白话）
- 现在不是不会证，是“该出哪条线”没把握。
- 他会乱画线，但不知道哪条线能把已知连到要证。
- 这周先盯：先看已知与目标，再决定出线。

直播 30 秒讲法
- “他不是不会画，是不知道哪条线有用。”
- “我点这条线，你看已知就能连到要证。”
- “本周就练一个动作：先看已知和目标，再出线。”

## 页面 4：几何样板2（证明骨架）

演示内容
把证明拆成“已知 -> 关键关系 -> 结论”的骨架，点击每一步展示需要的中间结论，强调“卡在不是不会写，而是缺一根中梁”。

页面结构
1. 顶部：标题 + 一句结论（先说孩子卡哪）。
2. 左侧主区：图形与可点选关系点。
3. 右侧骨架区：证明三段式骨架与缺口提示。
4. 底部操作条：重置与演示按钮。

按钮位置
- 右侧骨架区顶部：主按钮“补上中间这一步”。
- 底部操作条右侧：次按钮“重置”。

家长文案（大白话）
- 现在不是不会写，是“中间那一步缺了”。
- 题一换，他不知道该先证哪个关系。
- 这周先盯：先搭骨架，再填细节。

直播 30 秒讲法
- “他不是不会写证明，是骨架没搭起来。”
- “我补这一步，后面就顺着走了。”
- “本周先练骨架：已知到结论中间必须有桥。”
