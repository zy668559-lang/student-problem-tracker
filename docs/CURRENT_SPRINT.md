# CURRENT_SPRINT

## Sprint
U1.2 前台文案口语化真收口

## 本轮唯一目标
在不新增业务逻辑、不改后端契约、不碰多学生隔离底座的前提下，把家长端、学生端、会员页的前台文案统一改成陈老师口语化大白话，并清理内部术语和技术字段。

## 本轮只做什么
1. 改家长总览页文案
2. 改孩子首页文案
3. 改会员分层页文案
4. 改相关 CTA 按钮文案
5. 清理前台内部字段、内部 key、技术字符串
6. 真机和桌面重新验收页面表达

## 本轮明确不做什么
1. 不做正式支付/订阅
2. 不做 worker/cron
3. 不做新的业务逻辑
4. 不做底层表重构
5. 不做新的 API
6. 不改后端契约
7. 不动多学生隔离逻辑
8. 不重做页面结构

## 本轮完成标准
1. 家长页、孩子页、会员页全部改成大白话
2. 前台不再出现：
   - 证据时间轴
   - 定向素材
   - 老师纠偏
   - 学生自述
   - timeline-*
   - 内部字段名
3. 家长和孩子页面首屏能一眼看懂
4. 真机可访问并可截图验收
5. typecheck / build / playwright 全部通过
6. push 到 github/gitee 的 feature/mvp-init
