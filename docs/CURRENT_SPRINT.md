# CURRENT_SPRINT

## Sprint
D1 数据接口清单 + 自动录入待审核队列 + 人工审核确认流

## 本轮唯一目标
把“家长发作业 -> 自动抓取 -> 草稿诊断 -> 待审核 -> 人工确认 -> 正式入库”这条链设计并落成系统底座。

## 本轮只做什么
1. 设计并落地数据接口 / 事件合同
2. 新增自动录入待审核队列
3. 新增人工审核确认流
4. 把自动化搬运和正式学生档案写库拆开
5. 补后台最小审核入口和状态流转
6. 跑通从草稿到正式入库的最小闭环

## 本轮明确不做什么
1. 不做正式支付 / 订阅
2. 不做 worker / cron
3. 不做 Heartbeat Lite
4. 不做新的前台页面大改
5. 不重做多学生隔离底座
6. 不做全自动直接写正式库
7. 不做复杂消息网关集成

## 本轮完成标准
1. 已定义并落地核心事件 / 接口合同
2. 已有自动录入待审核队列
3. 自动抓取 / 录入结果不会直接写正式学生档案
4. 你可以在后台看到待审核草稿并确认入库
5. 审核通过后才正式写入学生档案
6. 审核动作会写审计记录
7. `npm run typecheck` / `npm run build` / `npm exec playwright test` 全部通过
8. push 到 `github/gitee` 的 `feature/mvp-init`
